Background & Context

The Physical-to-Digital Information Gap

Every day, thousands of public notice boards, medical clinics, and classrooms struggle to deliver rich digital knowledge to citizens through static paper.

📋

Static Notice Boards

Paper prints cannot play instructional videos, zoom into complex diagrams, or update dynamically once posted. This leads to information obsolescence and high reprint costs.

🔐

App & Account Fatigue

Traditional cloud drives (Google Drive, Dropbox) require logins, passwords, permission approvals ("Request Access"), and dedicated apps that discourage spontaneous learning.

🌱

Environmental Impact

Educational institutions, hospitals, and municipal offices print thousands of single-use sheets weekly, generating unnecessary waste and logistical friction.

Problem Definition

Formal Problem Statement

Addressing the digital divide and user friction in contemporary digital information exchange.

Core Problem Formulation

"Existing information distribution mechanisms force citizens either onto wasteful physical paper notices or through closed, high-friction cloud ecosystems demanding user accounts, app downloads, and personal phone number exchanges.

There is an urgent requirement for an open-access, zero-login physical-to-digital gateway enabling any mobile device camera to instantly stream instructional video, zoom into high-res images, and view educational or administrative documents directly in a lightweight browser."

Identified Key Bottlenecks

  • •
    Access Friction: "Permission denied" or "Sign in with Google" prompts when scanning public QR codes.
  • •
    Format Rigidity: Traditional QR generators handle only short web links or plain text, not native multi-format media.
  • •
    Network Isolation: Local development servers cannot be accessed by external scanners without specialized edge tunneling.
The Solution

LensQR: 3-in-1 Universal Media Gateway

A unified Python web architecture enabling one-click transformation of three media classes into scan-ready QR codes.

🖼️

1. Photo to QR

Converts photos (`.jpg`, `.png`, `.webp`) into unlisted responsive gallery viewers with pinch-to-zoom and clean layout for posters and art.

🎥

2. Video to QR

Converts instructional videos (`.mp4`, `.mov`, `.webm`) into native HTML5 video streaming players with HTTP 206 partial-content seeking.

📄

3. Document to QR

Converts PDFs, Word (`.docx`), Excel, PowerPoint & ZIP files into interactive in-browser PDF readers and single-click download cards.

Technical Architecture

End-to-End System Workflow

Seamless pipeline connecting creator uploads, security gates, and mobile scanners.

Layer 1: Security Shield

Magic-byte validation checks binary signatures (`%PDF-`, `PK..`) and blocks executables (`MZ`/ELF).

Layer 2: Cloudflare Edge

Encrypted outbound tunnel maps local Flask port 5000 to global HTTPS (`trycloudflare.com`).

Layer 3: Storage Engine

Atomic thread-safe JSON backup combined with Supabase cloud bucket signed URLs.

Under The Hood

Key Technical Innovations

Robust engineering decisions ensuring resilience, security, and low latency.

🛡️ Security & Integrity

  • •
    Magic Byte Inspection: Reads raw binary stream headers to prevent extension spoofing and Trojan uploads.
  • •
    Creator Token Security: Uploads issue random 256-bit authorization keys; only creators can delete or restyle their media.
  • •
    CSRF Defense: Double-submit CSRF cookie & header validation blocks cross-site request forgery attacks.

⚡ Performance & Reliability

  • •
    HTTP 206 Partial Content: Enables instant video scrubbing without forcing mobile users to download full files.
  • •
    Atomic JSON Engine: `os.replace` and `os.fsync` ensure zero file corruption even during unexpected reboots.
  • •
    Reed-Solomon QR Resilience: Level M/Q error correction allows up to 25% physical poster damage without scan failure.
